# 一起学习 RepoPilot

本项目先交付可运行实现，再用实际请求理解每一个设计。学习过程中不必一次读完全部文件。

## 1. 跟踪一次完整请求

启动工作台，导入演示仓库，提交 `calculate_total` 的数量为零问题。打开浏览器网络面板，对照 `api.py` 的创建任务、后台执行、事件、完成结果。练习：用自己的话解释为什么任务接口先返回编号，而不是一直等待最终回答。

## 2. 理解源码如何变成证据

阅读 `models.py`、`importer.py`，找到 AST 分块和行号保存的位置。打开 `cart.py` 核对引用。练习：添加一个超过 80 行的函数，再观察切分是否保持行号；思考函数上下文和索引成本的取舍。

## 3. 用实验理解检索

阅读 `retrieval.py` 的 BM25、符号匹配与 RRF。先在开发集比较带函数名和不带函数名的提问，再运行固定测试集。练习：改变候选数量，记录文件命中与延迟。hash 是词法基线，接入语义嵌入后才比较语义效果。

## 4. 理解 Agent 为什么循环

阅读 `graph.py` 的状态、路由和停止条件。对照界面轨迹，区分一次检索、补充查询和按行读文件。练习：把轮次预算改为 1 与 3，观察新增证据和调用成本；解释“多轮”在哪类问题上可能无收益。

## 5. 模型适配与可信输出

阅读 `providers.py`。在本地配置 DeepSeek 后比较演示与真实模式。练习：模拟 401、429、错误 JSON、伪造引用，检查哪些错误重试、哪些直接失败。不要在截图或提交中包含密钥。

## 6. 保存、恢复和可复现

阅读 `store.py` 与检查点测试。重启服务后检查任务历史；通过受控失败测试理解恢复边界。练习：解释事件存储、业务结果和 LangGraph 检查点为什么各有作用。

## 7. 把结果讲清楚

阅读评测协议和逐题结果，挑选成功与失败案例各两个。练习：说明基线、样本来源、指标分母、预算与局限；把“文件命中”和“修复成功”区分开。只有完成真实模型实验后，才把相应效果写进简历。

建议第一次一起学习从第 1 步开始，边操作边画出请求经过的模块，再进入检索和状态图。
